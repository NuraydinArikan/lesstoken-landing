```

(Next.js)                  (Flask)
```

## 1. Backend Deployment (Flask)

### Option A: Railway (Recommended - Simpler)

**1. Connect GitHub**
```bash
# Push code to GitHub
cd C:\Projects\lesstoken-landing
git add web/
git commit -m "feat: add web app backend (Flask API)"
git push origin main
```

**2. Deploy on Railway**
1. Go to https://railway.app
2. Login with GitHub
3. Click "New Project"
4. Select "GitHub Repo"
5. Choose lesstoken-landing repository
6. Select "Dockerfile" for deployment

**3. Configure Environment Variables**
In Railway dashboard → Variables tab, add:
```
FLASK_ENV=production
SECRET_KEY=<generate-random-string>
OPENAI_API_KEY=<your-key>
CLAUDE_API_KEY=<your-key>
GEMINI_API_KEY=<your-key>
DATABASE_URL=<auto-generated-postgres>
PORT=5000
```

**4. Set Custom Domain**
1. Railway dashboard → Settings
2. Add custom domain: `api.lesstoken.app`
3. Follow DNS instructions (add CNAME record in Porkbun)

**Cost:** $5/month for basic tier

---

### Option B: Fly.io (More Control)

**1. Install Fly CLI**
```bash
# Windows
choco install flyctl

# Or download from https://fly.io/docs/getting-started/installing-flyctl/
```

**2. Deploy**
```bash
cd web/
fly launch

# Follow prompts:
# - App name: lesstoken-api
# - Region: fra (Frankfurt) or nearest
# - PostgreSQL: Yes
# - Redis: No
```

**3. Set Secrets**
```bash
fly secrets set FLASK_ENV=production
fly secrets set SECRET_KEY=<random>
fly secrets set OPENAI_API_KEY=<key>
fly secrets set CLAUDE_API_KEY=<key>
fly secrets set GEMINI_API_KEY=<key>
```

**4. Deploy**
```bash
fly deploy
```

**Cost:** $0.003/hour (pay-as-you-go)

## 2. Frontend Deployment (Next.js)

**Already configured in lesstoken-landing repository**

### Update Next.js API Routes

Create `pages/api/v1/app.js` to proxy to backend:

```javascript
// pages/api/v1/[...path].js
export default async function handler(req, res) {
  const { path } = req.query;
  const backendUrl = process.env.NEXT_PUBLIC_API_URL || 'http://localhost:5000';

  try {
    const response = await fetch(
      `${backendUrl}/api/v1/${path.join('/')}`,
      {
        method: req.method,
        headers: req.headers,
        body: req.body ? JSON.stringify(req.body) : undefined
      }
    );

    const data = await response.json();
    res.status(response.status).json(data);
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
}
```

### Deploy to Vercel

**Already done** but ensure environment variables are set:

In Vercel Dashboard → Settings → Environment Variables:
```
NEXT_PUBLIC_API_URL=https://api.lesstoken.app
```

## 3. DNS Configuration

### Porkbun DNS Settings

**For api.lesstoken.app:**

1. Login to Porkbun
2. Go to lesstoken.app domain
3. Click "Manage DNS"
4. Add new record:

```
Type: CNAME
Name: api
Value: <railway.app or fly.dev domain>
TTL: 3600
```

**Example:**
- Railway: `lesstoken-api-production.up.railway.app`
- Fly: `lesstoken-api.fly.dev`

Wait 15-30 minutes for propagation.

## 6. Scaling

### When You Need to Scale

**If backend slow:**
- Railway: Upgrade plan
- Fly: Add more instances (`fly scale count=3`)

**If database slow:**
- Upgrade from SQLite to PostgreSQL
- Add indexes on frequently queried columns
- Implement caching (Redis)

**If frontend slow:**
- Enable Next.js Image optimization
- Add CDN (automatic with Vercel)
- Implement static generation for landing page

## 7. Database Management

### Backup Strategy

**SQLite (development):**
- Backup `lesstoken.db` weekly
- Store in GitHub (private repo)

**PostgreSQL (production):**
- Automatic backups on Railway/Fly
- Manual export quarterly

```bash
# Export PostgreSQL
pg_dump $DATABASE_URL > backup.sql

# Import
psql $DATABASE_URL < backup.sql
```

### Database Migrations

Track schema changes:

```bash
# Create migration
python -m flask db migrate -m "Add new column"

# Apply migration
python -m flask db upgrade
```

## 9. Error Handling & Logging

### Logs

**View logs:**
```bash
# Railway
railway logs

# Fly.io
fly logs
```

### Common Errors

**"Connection refused"**
- Backend not running
- Wrong API_URL in frontend
- Firewall blocking connection

**"Authentication failed"**
- Wrong JWT secret
- Token expired
- Malformed token

**"Database error"**
- Database connection string wrong
- Database not initialized
- Out of storage
